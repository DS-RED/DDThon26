# P3 — 고객용 테이블오더 앱

P3 유닛의 React/Vite SPA입니다. 기존 P1/P2 API를 소비하며 서버·DB·관리자 앱 소스는 변경하지 않습니다.

## 로컬 실행

Node.js 22.12 이상(검증 환경: 24.15.0), npm이 필요합니다.

터미널 1 — 저장소 루트에서 기존 서버 실행:

```bash
cd server
npm ci
npm run seed
npm start
```

터미널 2 — 저장소 루트에서 고객 앱 실행:

```bash
cd client-customer
npm ci
npm run dev
```

브라우저: `http://127.0.0.1:5173`. 최초 설정의 데모 값은 매장 `demo-001`, 테이블 `1`, 테이블 비밀번호 `0000`입니다. 이 값들은 시드 데이터 기준이며 앱에 자동 입력하지 않습니다.

API 기본 주소는 `http://localhost:3000`입니다. 변경 시 `.env.local`에 `VITE_API_BASE_URL`을 지정하고 개발 서버를 재시작하세요. 서버에서 CORS 허용 목록을 설정했다면 앱의 실제 오리진을 포함해야 합니다. 서버는 자신의 README에 따라 환경변수를 적용합니다.

## 구현 기능

- 최초 테이블 설정 및 로컬 저장, 인증 필요 요청의 401 발생 시 단일 재로그인. GET만 자동 재조회하며 주문 POST는 사용자 재확인을 받습니다.
- 카테고리 탐색, 메뉴 상세, 품절 카드 표시/담기 차단, 이미지 실패 대체 화면.
- 매장·테이블별 장바구니 저장/복원, 수량·삭제·정수 원화 합계.
- 최신 가격/판매 상태 확인 후 주문. 201 응답 확인 후에만 카트 초기화 및 주문 번호 표시. 5초 후 메뉴 복귀.
- 응답 유실 시 카트와 확인 필요 상태를 저장하고 재전송을 막습니다. 주문 내역/직원 안내를 통해 접수 여부를 확인한 뒤 사용자가 상태를 해제합니다.
- 현재 주문 내역/상세/한글 상태, 10건씩 페이지 표시, 재진입·포커스·수동 갱신.
- 태블릿/작은 화면 레이아웃, 접근 가능한 다이얼로그와 키보드 조작, 최소 44px 버튼.

## 검증

```bash
npm test
npm run build
```

기존 서버 의존성도 설치된 상태에서 브라우저 테스트:

```bash
npx playwright install --with-deps chromium
npm run test:e2e
```

Playwright가 `127.0.0.1:3101`에 기존 서버 모듈을 사용하는 **인메모리 DB 테스트 서버**, `127.0.0.1:5174`에 고객 앱을 실행합니다. 두 포트는 비어 있어야 합니다. 실제 로컬 DB를 수정하지 않습니다. 테스트 관리자 계정은 `e2e/` 픽스처에만 있으며 고객 번들에는 포함되지 않습니다.

브라우저 바이너리를 별도 위치에 설치하면 `PLAYWRIGHT_BROWSERS_PATH`를 설치·실행 모두 같은 값으로 지정하세요. 대체 Chromium 경로는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE`로 지정할 수 있습니다.

2026-09-07 검증 결과: **25개 단위/컴포넌트 테스트 통과, 잠금 파일 기준 npm ci 및 build 통과**. 브라우저 5개 시나리오는 작성했지만 이 환경의 `libnspr4.so` 누락으로 Chromium 실행 단계에서 차단되어 **실제 브라우저 검증 미완료**입니다. 실패 결과/trace는 `test-results/`에 생성되며 Git에서 제외합니다.

## 남은 계약 의존성

P1 현재 착석 세션 식별 계약이 필요합니다. 빈 `/orders/mine` 배열은 이용 완료와 활성 세션 내 주문 전부 삭제를 구별하지 못합니다. 따라서 빈 배열만으로 카트를 지우지 않습니다. **이용 완료 후 남은 장바구니 자동 초기화는 미구현**이며 P3 전체 인수 완료 상태가 아닙니다. 인증 JWT의 만료를 착석 세션 종료로 취급하지 않습니다.

서버의 멱등성 계약이 없어 네트워크 장애의 중복 주문 방지는 사용자 확인 절차까지가 현재 범위입니다. 전용 로컬 데모 태블릿의 자동 로그인 요구에 따라 설정/비밀번호가 브라우저 저장소에 남습니다. 설정 변경 버튼으로 현재 카트와 연결 정보를 초기화할 수 있습니다.

# P3 통합 검증 안내

실제 API 통합은 client-customer/e2e/customer-flow.spec.js에 정의되어 있다. 서버 의존성이 설치되어 있어야 한다. 테스트 시작 시 e2e/server.mjs가 기존 P1/P2 createApp, schema, seed를 인메모리 DB로 재사용한다. 서버 소스나 사용자의 DB는 변경하지 않는다.

로그인→메뉴→카트 새로고침→주문→내역→관리자 테스트 API를 통한 이용 완료→현재 내역 제외를 검증한다. 응답 거절과 응답 유실 시나리오는 오류 주입을 사용하며 정상 API와 구별한다. 응답 유실 테스트는 서버까지 실제 주문을 전달한 뒤 브라우저 응답만 끊는다.

환경 설정과 실행 명령은 e2e-test-instructions.md 참조. 이번 환경에서는 브라우저 시작이 실패하여 통합 시나리오를 검증하지 못했다.

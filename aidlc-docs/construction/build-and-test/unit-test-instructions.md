# P3 단위·컴포넌트 테스트

```bash
cd client-customer
npm test
```

Vitest + jsdom + React Testing Library. 4개 테스트 파일의 25개 테스트를 검증했다. 저장값 검증/매장·테이블 분리/불명확 주문 저장, 원화/UTC, 카트 수량·합계, 로그인, 품절, 주문 성공·실패·가격 변경·응답 유실, 401 복구, 페이지네이션을 포함한다.

app.test.jsx의 fetch는 목이다. 이 결과는 실제 HTTP 서버/브라우저 E2E 통과를 뜻하지 않는다. 빈 주문 배열에서 카트를 삭제하지 않는 회귀 테스트는 세션 자동 초기화 기능이 완료됐다는 뜻이 아니다.
